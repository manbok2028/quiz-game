# 🎯 나만의 퀴즈 게임

터미널에서 즐기는 **세금 상식 퀴즈 게임**입니다. Python 기본 문법과 클래스, JSON 파일 저장, Git/GitHub 활용을 처음부터 끝까지 직접 구현했습니다.

## 프로젝트 개요

- 터미널(콘솔)에서 동작하는 Python 퀴즈 게임입니다.
- 퀴즈 풀기, 퀴즈 추가, 퀴즈 목록, 최고 점수 확인 기능이 있습니다.
- 프로그램을 종료하고 다시 실행해도 추가한 퀴즈와 최고 점수가 유지됩니다.
- 외부 라이브러리 없이 Python 표준 라이브러리만 사용했습니다.
- 개발 환경: Python 3.10 이상 (WSL Ubuntu, VS Code에서 개발)

## 퀴즈 주제와 선정 이유

**주제: 세금 상식**

세금은 누구나 알아야 하지만 어렵고 낯설게 느껴지는 주제입니다. 국세와 지방세의 구분, 신고·납부 기한, 원천징수처럼 생활 속에서 자주 접하는 개념을 퀴즈로 풀며 쉽게 익힐 수 있다고 생각해 선택했습니다.

## 실행 방법

```bash
git clone https://github.com/manbok2028/quiz-game.git
cd quiz-game
python3 main.py
```

- Python 3.10 이상이 필요합니다. (`python3 --version`으로 확인)
- 별도로 설치할 라이브러리는 없습니다.

## 기능 목록

| 메뉴 | 기능 | 설명 |
|---|---|---|
| 1 | 퀴즈 풀기 | 저장된 퀴즈를 차례로 출제하고 정답 여부를 알려 줍니다. 모두 풀면 점수를 보여 주고 최고 점수를 갱신합니다. |
| 2 | 퀴즈 추가 | 문제, 선택지 4개, 정답 번호를 입력해 새 퀴즈를 등록하고 파일에 저장합니다. |
| 3 | 퀴즈 목록 | 등록된 퀴즈의 문제를 번호와 함께 보여 줍니다. |
| 4 | 점수 확인 | 최고 점수를 보여 줍니다. 아직 풀지 않았다면 안내 메시지를 출력합니다. |
| 5 | 종료 | 데이터를 저장하고 종료합니다. |

**입력/예외 처리**

- 입력 앞뒤 공백을 제거합니다.
- 숫자가 아닌 입력, 허용 범위 밖의 숫자, 빈 입력은 안내 메시지를 출력하고 다시 입력받습니다.
- 실행 중 `Ctrl+C`나 입력 스트림 종료(EOF)가 발생해도 안내 메시지를 출력하고 데이터를 저장한 뒤 안전하게 종료합니다.
- `state.json`이 없으면 기본 퀴즈로 시작하고, 손상되었으면 안내 후 기본 퀴즈로 초기화합니다.

## 파일 구조

```
quiz-game/
├── main.py        # Quiz, QuizGame 클래스와 프로그램 실행 코드
├── state.json     # 퀴즈와 최고 점수 데이터 (실행 시 자동 생성)
├── README.md      # 프로젝트 설명
└── .gitignore     # Git이 추적하지 않을 파일 목록
```

**클래스 구성**

| 클래스 | 역할 |
|---|---|
| `Quiz` | 퀴즈 1개를 표현합니다. 속성: `question`, `choices`, `answer` / 메서드: 퀴즈 출력, 정답 확인, dict 변환 |
| `QuizGame` | 게임 전체를 관리합니다. 속성: `quizzes`, `best_score` 등 / 메서드: 메뉴 표시, 퀴즈 풀기·추가·목록·점수 확인, 저장/불러오기 |

## 데이터 파일 (state.json)

- **위치:** 프로젝트 루트 (`main.py`와 같은 폴더)
- **인코딩:** UTF-8
- **역할:** 퀴즈 목록과 최고 점수를 저장해, 프로그램을 다시 실행해도 데이터가 유지되도록 합니다.
- **생성:** 퀴즈를 추가하거나 최고 점수가 갱신될 때, 그리고 종료할 때 자동으로 만들어지고 갱신됩니다. 직접 만들 필요가 없으며 Git에는 포함하지 않습니다.

**스키마**

| 키 | 타입 | 설명 |
|---|---|---|
| `quizzes` | 리스트 | 퀴즈 목록 |
| `quizzes[].question` | 문자열 | 문제 |
| `quizzes[].choices` | 문자열 리스트(4개) | 선택지 |
| `quizzes[].answer` | 정수 (1~4) | 정답 번호 |
| `best_score` | 정수 또는 null | 최고 점수 (100점 만점, 아직 풀지 않았으면 null) |
| `best_correct` | 정수 | 최고 점수일 때 맞힌 문제 수 |
| `best_total` | 정수 | 최고 점수일 때 전체 문제 수 |

**예시**

```json
{
    "quizzes": [
        {
            "question": "부가가치세의 기본 세율은?",
            "choices": ["5%", "10%", "15%", "20%"],
            "answer": 2
        }
    ],
    "best_score": 80,
    "best_correct": 4,
    "best_total": 5
}
```
